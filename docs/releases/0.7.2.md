# 留白 0.7.2

- 底层框架 MyGo 升级到 0.9.0。
- 注销、关机或重启电脑时，尚未保存的编辑会写进恢复日志；下次打开留白时接着写，最后一段输入不再丢失。
- 恢复出的内容是一份单独的「恢复副本」草稿，已保存的正文不会被旧版本覆盖。

macOS 安装包同时支持 Apple Silicon 和 Intel，需要 macOS 13 或以上。

Windows 版仍为内测版，提供 x64 与 ARM64 安装包。目前 Windows 程序和安装包没有代码签名证书，SmartScreen 可能提示「Windows 已保护你的电脑」；需要点「更多信息」→「仍要运行」。应用内更新包另有签名校验。
