# 主题与大纲：验证记录

对应 [设计](../specs/2026-10-22-themes-design.md) 和 [计划](../plans/2026-10-22-themes.md)，随 0.6.3 发布。

## 自动检查

发布前在与 v0.6.3 相同的代码上运行：

- `go test ./...`、`go vet ./...`、`go tool mygo i18n check`（498 条消息）、`tsc --noEmit`、`check-i18n`、`check-editor` 和 `check-themes.mjs`（11 套主题的对比度门槛与清单）全部通过。
- 16 项 bun 单元检查全部通过。其中 `check-theme.ts` 用 2026–2050 年的天文数据核对节气公式。
- Chrome 回归 15 项中 14 项通过。`check-mermaid` 只有最后一条 CSP 断言失败：它的 `<svg onload>` 样例在 Chrome 156 下会报告 `script-src-attr`。没有这次改动的 `7c67d48` 也一样失败，与主题无关。
- Windows CI（windows-latest 上的 go vet 和 go test）在 `c0ba12b` 上通过。

## 桌面应用实测（macOS，部分完成）

2026-10-23 用独立的测试包检查：bundle id `app.liubai.desktop.nativetest`，单独的数据目录和 HOME，只用辅助功能操作，不抢焦点。

- **外观面板**：11 套主题的名称、说明和「自动切换」都在。在关、跟随系统、跟随天光、跟随四季之间切换时，面板上沿位置不变。
- **自动切换**：跟随天光在 11:41 得到纸白，跟随四季在 10 月 23 日得到秋香，跟随系统（浅色）得到纸白。
- **大纲**：1512 宽的窗口里只有一份大纲，在正文右侧；侧栏只显示「最近文稿」。
- **没在桌面应用里做的**：从面板逐一选另外 9 套主题、1180 宽窗口的大纲弹出层、随手记。实测中途屏幕自动锁定（300 秒无操作），锁屏后 WKWebView 不再绘制。
  - 前两项在屏幕外的 WebKit 窗口里用网页版检查通过，和桌面版是同一个 WebKit。
  - 随手记只有 Chrome 回归（`check-capture`）覆盖。
- **原有问题**（不是这次引入）：
  - 阅读视图里代码注释是斜体，中文注释会被拉斜。
  - 点大纲条目后，标题停在视口底部而不是顶部。

## Windows

这一版没有在 Windows 真机上验证。主题相关的 Windows 代码只经过 CI 的 go vet 和 go test，包括标题栏按钮和菜单跟随深浅色、跟随天光时每分钟检查一次。
