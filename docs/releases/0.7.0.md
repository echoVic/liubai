# 留白 0.7.0

- 新增「工作坊」系列 14 套主题，总计 25 套。包括 GitHub 浅深色、Solarized 浅深色、Monokai、Nord、Atom One 浅深色、Dracula、Catppuccin 浅深色、Gruvbox 浅深色和 Rosé Pine；网页与桌面设置均可选择。
- 阅读图片可以打开大图，在适应窗口和原始尺寸之间切换，支持键盘操作与平移。宽表、长代码和文稿属性可以单独横向滚动。
- 阅读与分栏预览在连续编辑、切换主题和语言时保留表格、代码的横向位置及折叠状态；切换视图、调整字号和行宽时更稳定地保持阅读位置。新的键盘或滚动操作会取消旧的滚动恢复。
- 窄屏和矮屏下，格式工具栏在一行内横向滚动；恢复提示和对话框可完整显示操作。改进菜单分组、表格对齐选中状态、控件名称、焦点提示和对话框关闭后的焦点返回。
- 修复复制富文本到 TextEdit 后的中文乱码、流程图样式混入正文和公式重复。图表以 PNG 交付，基本富文本中的公式保留一份 TeX 源码；HTML、PDF、Word 的公式交付方式保持各自格式。
- 修复原始 HTML 链接、图片路径及说明中的部分文字被误删；切入阅读模式后取消尚未完成的纯文本粘贴。
- 修复从 TextEdit 粘贴回来时，加粗标记不闭合和表格单元格被段落换行拆散的问题。纸面导出展开折叠内容，保持浅色排版。

macOS 安装包同时支持 Apple Silicon 和 Intel，需要 macOS 13 或以上。

Windows 版仍为内测版，提供 x64 与 ARM64 安装包。目前 Windows 程序和安装包没有代码签名证书，SmartScreen 可能提示「Windows 已保护你的电脑」；需要点「更多信息」→「仍要运行」。应用内更新包另有签名校验。
