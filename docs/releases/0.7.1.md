# 留白 0.7.1

- 菜单和设置里新增「问题反馈…」，打开 GitHub 的问题表单。底层框架 MyGo 升级到 0.8.3；设置里录制随手记快捷键时按键位识别，不受输入法和键盘布局影响。
- 修复文稿在别处变化后无法保存、一直卡住的问题：提示条现在提供「重新载入」和「另存为」。重新载入会放弃尚未保存的输入。
- 从访达、「打开方式」、拖放或再次启动打开文件时，不再丢弃正在输入的草稿；这些入口只接受 Markdown 和文本文件。
- 另存为：标题里的句点和斜杠不再被截掉；不能再覆盖另一篇已打开文稿的文件；同一个文件换大小写、经链接或硬链接打开时算作同一篇文稿。图片在嵌套列表里时，另存为、ZIP 导出和保存恢复副本不再失败；覆盖失败后不再留下多余的「磁盘版本」副本。
- 标题叫 Toast、Drawer、Commands 这类名字时，阅读和分栏视图里的提示、侧栏、命令面板不再失灵。大纲按读到的样子显示标题（不带标记、链接地址和 HTML 标签），不再列出空标题。
- 编辑时，引用式链接、`<…>` 自动链接和裸网址可以 ⌘/Ctrl 点击打开；没有定义的引用保持普通文字。提示块的写法与 GitHub 一致，编辑和阅读结果相同。离开表格或图片时，旁边是公式或 Mermaid 图表也会空出一段。
- 双链：`[[1] …](url)` 这类引用之后、非链接的方括号文字之中的双链都能识别；转义的 `\]]` 以及代码、公式、HTML 里的 `]]` 不再结束双链；恢复副本和磁盘版本副本不再作为双链目标。
- 粘贴：表格单元格里的 `|` 和换行、高亮、下划线、上下标得以保留；从 Office 粘贴时使用文字内容而不是附带的图片；粘贴的图片被别的程序改动后不再妨碍保存。
- 导出：Word 里的公式按 MathML 的字体样式排（单字母变量斜体，函数名、数字正体，粗体、黑板粗体、花体保留）；导出的提示块使用浅色主题的颜色；HTML 标题里的 `&`、`<`、`>` 保留；未命名草稿导出 Word 时标题随界面语言；导出按钮的提示补上 Word。
- 草稿标题的推断：`[WIP] …` 保留方括号，文稿属性里的 `title` 按 YAML 读取，公式块、空任务项和链接定义不再被当成标题。随手记写入标签时保留同一行的注释，`&`、`<`、`>` 不再被转义。声明了其他编码或根标签很长的 SVG 可以插入。
- 「工作坊」主题：悬停、分隔线、当前项、搜索与高亮标记、代码块底色在 Solarized、Monokai、Nord、One Dark、Dracula、Catppuccin、Gruvbox、Rosé Pine、One Light、GitHub Dark 等 13 套里看得清了；Monokai 的危险色改为橙色。深色主题的阴影和对话框遮罩改为压暗，不再发亮。英文界面里 Catppuccin 深色的标签是 Mocha，One Light 的标签是 Letter。
- 标题 4–6 的字号随所选字号变化，编辑和阅读一致。网页版字号可选 15–22，与桌面设置一致；网页版「打开」也接受 `.mdown` 和 `.mkd`。阅读视图里的链接显示手形指针。外观色板的焦点框在每套主题下都看得见。接连改字号和行宽时，编辑区不再偏离原来的位置。
- 桌面设置窗口：选中的分段、悬停和按下状态在所有主题下可见；「工作坊」每行 4 套；选中的卡片不再让内容偏移 1 像素。窗口第一帧使用主题底色。macOS 上切换语言后，窗口位置、「打开最近使用」和更新选择保留。
- 快捷键：桌面版的菜单快捷键只由菜单处理；Windows 上 Ctrl+Shift+F 留给输入法，专注模式用 F8；macOS 上 Ctrl+N/O/P/K/S 不再触发新建、打开、导出 PDF、所有操作和保存。从「所有操作」打开查找后焦点留在查找框，应用链接后焦点回到正文。
- 输入法组字期间切换语言，标题、保存状态、字数和标题级别不再被重置。本地服务停止时显示本地化的提示。
- 性能：标签筛选和反向链接更快；在表格、图片、公式和任务项附近打字时不再重建它们；侧栏列表不再每次按键都重建；分栏预览复用已高亮的代码块。每篇文稿的光标与撤销记录只为最近打开的 8 篇保留。
- macOS 13.0 上，对话框遮罩、随手记面板底色、提示条、主要按钮的悬停和搜索命中不再消失。

macOS 安装包同时支持 Apple Silicon 和 Intel，需要 macOS 13 或以上。

Windows 版仍为内测版，提供 x64 与 ARM64 安装包。目前 Windows 程序和安装包没有代码签名证书，SmartScreen 可能提示「Windows 已保护你的电脑」；需要点「更多信息」→「仍要运行」。应用内更新包另有签名校验。
