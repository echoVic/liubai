# 块编辑设计

**日期**：2026-10-17
**状态**：已与用户确认方向与分期，第一期开发中

## 背景与决定

用户认为编辑能力需要补齐，并指出主流 Markdown 编辑器已经是块（block）架构。讨论后确定：

- **定位**：留白是 Markdown 文件编辑器（Typora / Obsidian 一类），文件就是 .md，打开和写回都保持原文，能和其他工具、Git 互通。这也是 egoist/mygo#274「Markdown 阅读器和实时编辑器」的方向。
- **架构**：块是交互层，不另建文档模型。Markdown 文本是唯一来源，块从 CodeMirror 的 Lezer 语法树实时推算；每个块操作都落成一次文本修改。
- **能力**：块操作、斜杠菜单、所见即所得的表格与图片、公式图表与扩展语法，全部要做，分三期。
- **图片尺寸写法**：调整过大小或对齐的图片写成 `<img src="…" alt="…" width="300">`（居中等对齐用 `align`），GitHub、VS Code、Typora、Obsidian 都能按尺寸显示；没调整过的图片仍是 `![说明](路径)`。
- **其余语法**按业界通行写法：公式 `$…$` / `$$…$$`，图表 ` ```mermaid `，提示块 `> [!NOTE]`，折叠块 `<details>`，脚注 `[^1]`。

不采用的方案：把编辑器换成 ProseMirror 一类块文档框架（Milkdown、Tiptap、BlockNote、Vditor 等）——它们把 Markdown 转成内部模型再生成，会改写用户文件的写法，整篇渲染也拖慢长文，并且要重新验证中文输入法；每个块一个编辑框的仿 Notion 结构——跨块选择、撤销和输入法都要重做。

## 块的定义

由语法树推算，不存储：

- 顶层块是 `Document` 的直接子节点：段落、ATX / Setext 标题、引用（含提示块）、围栏代码、缩进代码、表格、分割线、HTML 块。
- 列表里的每个列表项都是一个块；嵌套的列表项是它的子块，移动列表项时连同子块一起移动。
- front matter 不是块，不显示手柄，也不能被移动或转换。
- 块的范围是从第一行行首到最后一行行尾（不含末尾换行）。块之间的空行是分隔，不属于任何块。

## 块操作（第一期）

所有操作都是一个 CodeMirror 事务、一步撤销；只修改涉及的范围，其余字节不变。

- **移动**：与同级的前一块或后一块交换（⌥⇧↑ / ⌥⇧↓），或拖到某一块之前或之后。顶层块之间保留原有的空行分隔；列表项只在同一列表内、同一层级间移动，保持紧凑或松散列表原来的写法；移动后光标或选择跟随块。有序列表移动后重新编号。
- **转换**：正文、标题 1–3、无序列表、有序列表、任务、引用、代码块，复用并扩展 `src/editing.ts` 现有的 `blockFormat` / `setHeading` / `codeBlock`。
- **复制一份、删除**：作用于整块（含列表子块）。
- **选择**：点块手柄选中整块；按住 ⇧ 再点另一块手柄，选中两者之间的连续块；选中的块有高亮；上述操作作用于所选的全部块。

### 界面

- 鼠标悬停某块时，正文栏左侧外沿出现 ⋮⋮（拖动 / 打开块菜单）和「+」（在下方插入）。只在编辑视图和分栏的即时排版中出现；源码模式、阅读视图、专注模式、只读状态、中文组字期间都不出现。
- 拖动 ⋮⋮ 超过 4px 开始拖动：被拖的块半透明，块与块之间出现一条插入线；Esc 取消；靠近上下边缘时自动滚动；松开后移动。
- 点 ⋮⋮ 选中该块并打开块菜单：转换为（正文、标题 1–3、无序列表、有序列表、任务、引用、代码块）、复制一份、删除、上移、下移。菜单复用现有菜单组件的键盘操作。⌘/ 为光标所在块打开同一个菜单。
- 文案全部进入中英两份目录。

## 斜杠菜单（第一期）

- 在空行（或只有空白的行）的开头输入「/」时弹出插入菜单；中文标点状态下这个键输出「、」，在空行开头也同样触发。中文组字期间不触发。
- 菜单项：正文、标题 1、标题 2、标题 3、无序列表、有序列表、任务列表、引用、代码块、表格、图片、分割线、提示块。每项有中文名、英文名和关键词（全拼、拼音首字母、英文），继续输入即过滤，例如 `/bt` 或 `/heading` 找到标题。
- ↑↓ 选择，Enter 或 Tab 确认，Esc 关闭并保留已输入的文字；没有匹配时关闭。
- 确认后删除「/查询词」，把当前行变成对应的块：表格插入 2×2 的表格并把光标放进第一个单元格，图片打开现有的图片选择，提示块插入 `> [!NOTE]` 和一行空引用，分割线插入 `---` 并在下方留出空行。
- 块手柄的「+」在当前块下方插入一个空段落并在那里打开同一菜单。
- 后续两期把表格、图片的所见即所得编辑和公式、图表、折叠块、脚注加入菜单。

## 第二期：所见即所得的表格与图片

- 表格：光标离开时的表格部件改为可直接编辑：点击单元格就地输入，Tab / ⇧Tab 跳格，表头菜单可插入或删除行列、设置左中右对齐；所有修改都重新生成该表格的 Markdown，且只替换表格范围。现在的表格弹窗下线。
- 图片：选中图片时出现角上的拖动柄调整宽度，工具条提供左中右对齐和说明文字；调整后写成 `<img width>` 形式，恢复原始大小时回到 `![说明](路径)`。编辑区、阅读视图和导出按同样的尺寸显示。

## 第三期：公式、图表与扩展语法

- KaTeX：行内 `$…$` 和整段 `$$…$$`，光标在公式外时显示渲染结果，进入时显示源码；阅读视图和导出同样渲染。
- Mermaid：` ```mermaid ` 代码块在编辑区和阅读视图中显示为图；导出为内嵌 SVG。Mermaid 体积约 3 MB，只在文稿含图表时按需加载。
- 提示块 `> [!NOTE]` 等在编辑区也按类型着色；折叠块 `<details>` 可在编辑区折叠展开；脚注提供插入命令和悬停预览。

## 贯穿约束

- **原文不动**：往返测试覆盖每个块操作——只改涉及范围，其他字节（包括空行写法、列表符号、缩进）不变。
- **中文输入法**：组字期间不推算块、不显示手柄、不弹菜单，沿用现有的组字保护。
- **性能**：手柄只为可见区域计算；块推算复用语法树，不增加每次按键的开销，`check-performance.ts` 预算照常通过。
- **可访问性**：块菜单可由键盘打开和操作；手柄有名称和提示。
- **体积**：KaTeX 约 0.3 MB 脚本加字体；Mermaid 按需加载。安装包预计从 9.5 MB 增至约 11 MB。

## 测试

- 块模型与操作：Bun 单元测试（与 `scripts/check-editing.ts` 同风格），覆盖各类块的识别、移动、转换、复制、删除、列表子块、有序列表重编号、撤销一步还原、未涉及字节不变。
- 界面：新的浏览器回归 `scripts/check-blocks.py`，覆盖手柄出现与隐藏、拖动重排与撤销、点击选中与 ⇧ 连选、块菜单转换、键盘移动、斜杠菜单的过滤与插入、「、」触发、组字期间不触发。
- 原生：用隔离测试包确认手柄和菜单在 WKWebView 中显示、块菜单可用（辅助功能操作）。
