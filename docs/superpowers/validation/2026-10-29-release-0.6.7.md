# 0.6.7 提交与发布准备

用户于 2026-10-29 要求「提交代码并准备发布 0.6.7」。本次范围为本地提交、正式安装包与更新包准备，不推送远端或发布 GitHub Release。

后续用户要求「现在推送官网并准备发布 0.6.7」，授权推送官网及版本代码、标签，并准备远端 Release 草稿。当前状态见文末。

## 发布内容

全文搜索、标签筛选、双链及反向链接、浮动文内查找、独立设置窗口、随手记模板与标签追加，以及按原截图恢复的主题卡片。用户发布说明见 [0.6.7](../../releases/0.6.7.md)。

## 提交前复审

三轮独立分区审查后修复以下问题：

- 追加标签拒绝会破坏 YAML 锚点引用的属性写法，错误时保留原文件。五个锚点回归先失败后通过。
- Go 与前端统一 front matter 结束行规则；裸 URL 中的双链样式文字不作为引用，紧挨 URL 的独立双链仍可识别。FTP 路径与预览保持一致。共享语法样本从 51 扩展到 60 条。
- 可取消的搜索导航保留原稿，取消时恢复后端当前文稿。真实 API 回归先复现「保存失败」，修复后确认空白原稿仍能继续输入、保存及重启恢复。
- 追加速记后刷新文内查找计数，保持当前选区；真实 API 回归先复现「未找到」残留，修复后为 `0 / 1`。
- 阅读查找按正文显示规则折叠软换行和连续空格，记录准确 UTF-16 DOM 端点；代码和不换行空格保留原义。23 个 Chrome 专项检查覆盖范围映射及高亮几何，修复前 10 个用例失败。
- 请求 DTO 用于实际 API 参数，TypeScript 检查验证调用边界。
