# 块编辑第二期实施计划：所见即所得的表格与图片

> 设计：[2026-10-17-block-editing-design.md](../specs/2026-10-17-block-editing-design.md)「第二期」。实现者为本机 Codex CLI，编排者审查、跑全部检查（含 WebKit 离屏检查）后提交并发布 0.2.x。

**全局约束**：Markdown 文本是唯一来源；每次编辑只替换该表格或图片的范围，一步撤销；中文组字期间不提交单元格内容；源码模式下表格和图片都是原文；新文案中英双语；`check-performance.ts` 预算照常通过；不新增依赖。

## 任务 1：表格就地编辑

- 光标在表格外和表格内都显示为表格部件（不再在光标进入时退回源码）；源码模式仍是原文。
- 点击单元格即可输入；Tab / ⇧Tab 在单元格间移动，最后一格按 Tab 新增一行；↑↓ 在同列上下移动，从首行/末行再按会离开表格回到正文；Esc 把光标放回表格后的正文。
- 表格右上角（或悬停表头时）出现表格菜单：在上方/下方插入行、在左侧/右侧插入列、删除行、删除列、本列左对齐/居中/右对齐、删除表格。
- 每次修改用现有的 `parseTable` / `serializeTable` 重新生成该表格的 Markdown，只替换表格范围；单元格内的 `|` 转义为 `\|`，行内 Markdown 原样保留；没改的单元格文字不变。
- 编辑过程中部件就地更新（`WidgetType.updateDOM` 或等效做法），不因重绘丢失焦点和光标位置。
- 现有的表格弹窗下线，格式栏和斜杠菜单的「表格」插入 2×2 表格并把光标放进第一个表头单元格。
- 测试：Bun 覆盖增删行列、对齐、转义、只替换表格范围；浏览器回归覆盖点格输入后 Markdown 更新、Tab/⇧Tab/末格 Tab 新增行、↑↓ 离开表格、表格菜单各项、撤销一步还原、合成组字期间不提交、英文菜单；WebKit 离屏检查覆盖单元格输入。

## 任务 2：图片大小、对齐与说明

- 点击图片显示选中框、右下角拖动柄和图片工具条：左对齐、居中、右对齐、原始大小、说明文字（编辑 alt）、删除。
- 写法（设计已定）：未调整的左对齐图片保持 `![说明](路径)`；调整过宽度写成 `<img src="路径" alt="说明" width="300">`；居中或右对齐时外包 `<p align="center|right">…</p>`；「原始大小」且左对齐时回到 `![说明](路径)`。
- 编辑区把单独成行的 `<img …>` 与 `<p align><img …></p>` 也显示为图片部件，宽度和对齐与阅读视图、导出一致；阅读视图的消毒保留 `width`、`align`。
- 拖动时实时显示宽度，松开后写入；宽度取整像素，不超过正文栏宽度。
- 测试：Bun 覆盖各种写法的互相转换和原文其余部分不变；浏览器回归覆盖拖动改宽度、对齐、原始大小、改说明、删除、撤销、阅读视图同尺寸显示；WebKit 离屏检查覆盖拖动柄。
