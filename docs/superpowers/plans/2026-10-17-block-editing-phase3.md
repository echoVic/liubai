# 块编辑第三期实施计划：公式、图表与扩展语法

> 设计：[2026-10-17-block-editing-design.md](../specs/2026-10-17-block-editing-design.md)「第三期」。用户在第二期时选定工具栏的公式、图表、脚注按钮随本期加入。实现者为本机 Codex CLI，编排者逐任务审查、跑全部检查（含 WebKit 离屏检查）后提交，最后发布 0.4.0。

**全局约束**：Markdown 文本是唯一来源，渲染只是显示，写回的字节由用户的输入决定；光标在公式、图表等元素外时显示渲染结果，进入时显示源码（与现有图片、行内标记一致）；中文组字期间不重算、不弹出；源码模式下一律显示原文；编辑区、阅读视图和导出渲染一致；新文案中英双语；四套主题；`check-performance.ts` 预算不变。新增依赖只有 KaTeX 0.19.0 与 Mermaid 12.1.0（锁定版本，均已发布两周以上），全部随应用离线提供，不访问网络、不放宽内容安全策略（`script-src 'self'`）；新增依赖的许可写入 `web/THIRD_PARTY_NOTICES.txt`。

## 任务 1：公式（KaTeX）

- 语法：行内 `$…$`、整段 `$$…$$`（单独成段，可跨行），以及 GitHub 的 ` ```math ` 代码块。行内规则与 GitHub / Pandoc 一致：开头的 `$` 后不能是空白，结尾的 `$` 前不能是空白、后面不能紧跟数字；`\$` 是普通字符；代码里的 `$` 不算公式。因此「$5 和 $10」不是公式。
- 编辑区：Lezer 扩展识别行内公式和整段公式。行内公式渲染为行内部件，整段公式和 ` ```math ` 渲染为块部件，居中显示；光标进入时显示源码。公式有错时显示原文和错误提示，不报异常。
- 阅读视图与导出：markdown-it 规则与 Lezer 规则一致，用同一份 KaTeX 渲染。PDF 与阅读视图相同。导出的 HTML 文件和富文本复制不能依赖应用里的字体和样式表，改用 KaTeX 的 MathML 输出（浏览器原生显示），除非每个文件内嵌所需样式和字体不超过 100 KB。
- 工具栏「公式」（Lucide `sigma`）：有选区时包成 `$…$`；在空行上插入整段 `$$` 块，光标放在中间；其他位置插入 `$$` 并把光标放进去。斜杠菜单和插入菜单增加「公式」（整段）。
- 字体只带 woff2；报告安装包体积变化。

## 任务 2：图表（Mermaid）

- ` ```mermaid ` 代码块在编辑区（光标在块外时）和阅读视图中显示为图，光标进入时显示源码；图跟随主题（夜墨用深色主题）；语法错误时显示错误信息，源码照常可编辑。
- 按需加载：Mermaid 单独打包为一个按需加载的文件（esbuild 分包），只有文稿里出现 mermaid 代码块时才加载；没有图表的文稿不加载它。渲染结果按源码和主题缓存。`securityLevel: 'strict'`，不允许脚本和点击回调。
- 导出：HTML、PDF、富文本复制中为内嵌 SVG，导出前等待渲染完成；渲染失败时导出保留代码块原文。
- 工具栏「图表」（Lucide `workflow`）和斜杠菜单「图表」插入一个小的流程图模板，光标放在模板里。

## 任务 3：提示块、折叠块与脚注

- 提示块：`> [!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]` 在编辑区按类型着色（左边线与浅底色，与阅读视图一致），光标不在首行时 `[!NOTE]` 显示为本地化的类型名（备注、提示、重要、警告、注意）。
- 折叠块：`<details>` HTML 块在编辑区的 `<summary>` 行前显示折叠开关，折叠后只显示摘要行；折叠状态只在编辑区，不写入文件；可用键盘操作。斜杠菜单增加「折叠块」，插入带 `<summary>` 的模板。
- 脚注：工具栏「脚注」（Lucide `sticky-note`）和斜杠菜单「脚注」在光标处插入 `[^n]`（n 为下一个未用的编号），在文末追加 `[^n]: ` 定义并把光标放到定义处，一步撤销；编辑区的脚注引用显示为上标样式，悬停显示定义内容，⌘ 点击跳到定义。
