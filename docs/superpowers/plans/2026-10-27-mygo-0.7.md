# 升级 MyGo 0.7.1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 留白从 MyGo 0.6.0 升到 0.7.1（mygo-runtime 同步到 0.7.1），并删掉升级后不再需要的变通代码。

**Architecture:** 先换依赖、重新生成代码、全量检查保持全绿（Task 1）。在此基础上分两路并行：Go 端清理（Task 2，Codex，另一个 worktree），前端的标题栏留白（Task 3，traecli，接在 Task 1 之后）。各自在分支上提交，最后由 Claude 用 git 合并、统一复跑。

**Tech Stack:** Go 1.27.3 + MyGo 0.7.1，TypeScript + CodeMirror 6，esbuild，bun 1.4.3（安装）/ bun（单元检查），Python Playwright + Chrome（浏览器回归）。

## 背景与决定

用户 2026-10-27 决定升级 MyGo 0.7.1 并做相应的重构。Claude 已在本 worktree 试过：`go get github.com/egoist/mygo@v0.7.1` 之后 `go build ./...` 和 `go vet ./...` 都直接通过，`go.mod` 的 `go` 指令随之升到 1.27.3（0.7.1 的最低要求）。这两处改动已在工作区里，未提交。

0.6.1–0.7.1 里与留白有关的变化，以及这次的取舍：

- **#592（0.6.1）**：`RequestSingleInstanceLock` 在把文件交给已运行的实例时，会调用 `AllowForeground()`。留白自己的 `allowForegroundHandoff` 可以删掉（Task 2）。区别：留白以前在每次非登录启动时都放开前台权限，MyGo 只在交接时放开，后者更合适。
- **原子保存（0.6.4）**：临时文件改名覆盖被监视的文件，现在报一次写入，而不是先删后建。留白用 `mygo.WatchFiles` 监视文稿（`desktop_watch.go`），要补测试确认行为正确（Task 2）。
- **安装包命名（0.7.0，破坏性）**：DMG 和 Windows 安装包改按 slug 命名。留白的 slug 是 `liubai`，以后是 `liubai-<版本>.dmg`、`liubai-setup-<版本>-amd64.exe`、`liubai-setup-<版本>-arm64.exe`，文件名里没有空格，GitHub 也就不再把空格换成点。更新包（`liubai-<版本>-<平台>.tar.gz`）和更新清单（`update-<平台>.json`）的名字不变，已安装的留白照常更新。有更新的应用还会多出 `install.sh` 和 `install.ps1`。文档要跟着改（Task 1）。官网的下载链接由 Claude 在下次发版时改。
- **版本号**：`App.Version()` 默认就是打包时写进应用的版本（`mygo.json` 的 `version`）。`main.go` 里写死的两处可以去掉，发版只改 `mygo.json` 和 `package.json`（Task 2）。
- **标题栏留白**：MyGo 从页面的第一帧起就提供 `--mygo-titlebar-inset-left`，全屏时为 `0px`。留白在 macOS 上写死 `padding-left:88px`，全屏时左边白白空着一截；改用变量（Task 3）。

不做的（理由）：

- **`Window.SetWindowButtonsTheme`（0.7.0）**：它只改 Windows 标题栏按钮，菜单仍跟随系统。留白现在用 `Theme.SetSource`，让按钮和菜单都跟随留白的主题，这是有意的（`main.go` 的 `syncWindowTheme`）。
- **用 MyGo 从文案生成本地化的应用名**（代替 `mygo.json` 里的 `CFBundle*` 键和 `resources/*.lproj`）：本地构建 macOS 版要签名，没法低成本验证，留到以后。
- **`appNameFor`**：应用名同时是身份的问题，上游还没改（Claude 会开 issue），保留。
- **页面里改用 `runtime().platform`**：`navigator.platform` 在 WKWebView 和 WebView2 里都可靠，浏览器回归也靠伪造它来模拟 Windows，改动收益小。

## Global Constraints

- **不推送。** 在各自的分支上提交（提交信息跟随仓库风格：英文、`build:`、`refactor:`、`docs:` 等前缀，标题是完整短句，正文说明原因），由 Claude 合并。
- 不加依赖。`bun.lock` 是 lockfileVersion 2，本机的 bun 1.3.11 读不了。改依赖要手改 `package.json` 和 `bun.lock` 里该包的两行，再运行 `npx --yes bun@1.4.3 install --frozen-lockfile`；之后 `grep -c 'https://' bun.lock` 必须是 0：这个文件只记默认源的包，出现网址就说明混进了别的源，而仓库是公开的。
- `web/` 只用 `node scripts/build.mjs` 生成；`locales.ts`、`locales/catalog_gen.go`、`bindings.ts` 只用 `go tool mygo generate` 生成。
- 代码风格跟随周围代码（TS 和 CSS 是紧凑单行写法，Go 改完 `gofmt`），注释用英文。
- 不跑原生 GUI 测试，不运行 `go tool mygo build`（会弹出钥匙串签名），不碰 /Applications 里的留白和用户数据目录。
- 浏览器回归用 `scripts/e2e.sh <check> [端口]`；跑之前先 `node scripts/build.mjs`。负载高时偶发超时，先单独重跑一次；仍失败就停下来写进报告。已知与此无关的失败：`check-mermaid` 最后一条 CSP 断言。
- Go 缓存没有写权限时，用 `GOCACHE=/tmp/liubai-mygo07-gocache`。
