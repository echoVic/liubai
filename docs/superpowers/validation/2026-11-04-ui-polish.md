# 全模块 UI 打磨验收

日期：2026-11-04；补充检查：2026-11-05。范围依据 `PRODUCT.md`、当前页面入口和模块代码；保留“编辑为主、平整纸面、低干扰”的产品方向。

本轮代码与浏览器验收已通过。模块清单来自完整产品范围；已有检查覆盖、专项缺陷复现和修复后的回归分别保留证据，避免用单一模块通过代替整体验收。点名工具的可用性限制及原生系统交互的验证边界见下文。

## 本轮修正

- 图片查看器支持 Tab、Enter/Space 切换原始尺寸，方向键平移；放大图从左上角开始滚动，四边都可达。弹窗复用及打开期间切换语言会同步更新控件名称，焦点由固定在窗口内的白色边框指示。
- 切换视图后的滚动恢复会让位于用户的新操作。控制下一帧的检查曾复现 Home 已定位到开头、滚动却被恢复到约 8600px 的问题；加入取消保护后恢复为 0px。
- 手机和矮屏工具栏保留完整操作组，在自身横向滚动，避免多行工具挤占正文。末尾工具的键盘焦点会校正局部滚动，支持真实 Tab 路径和合成触摸横滑。
- 640–819px 宽且不高于 400px 的矮屏分栏采用左右并排，保留足够的正文高度；其他窄屏保持上下排列。
- 窄屏冲突提示先显示说明，再排布恢复操作；中英文操作文案允许换行，按钮边界和 hover 都使用控件色。
- 长代码和展开后的文稿属性仅在横向溢出时增加具名键盘区域，支持 Tab 进出和方向键滚动，焦点与滚动条使用主题色。分栏编辑和主题/语言刷新时保留横向位置及折叠状态，新文稿从默认状态开始。
- 对话框显式记录打开控件。WebKit 中点击按钮通常不会自动聚焦，过去关闭导出、重命名或外观对话框会把焦点留在页面；链接编辑取消也存在类似问题。返回目标现由控件直接传递，键盘打开仍使用原焦点。
- 阅读状态随原文区段移动：在代码、表格或折叠内容上方增删正文、插入重复块后，原块保持横向位置与展开状态。块内输入代码、修改单元格和折叠正文也保留状态；替换后的代码、表头、HTML 表格标题或折叠标题使用新内容的默认状态。作者 HTML 的代码、表格和折叠元素补充原文行范围，避免按排列序号误配。

## 跨模块验收

`layout-states` 组合检查包含中英文、编辑/分栏/阅读、侧栏停靠/覆盖、文内查找及替换、冲突提示和导出对话框。核对 1440×900、900×700、360×640、320×568、740×320，检查控件边界、可用正文空间和焦点恢复。字号与行宽另由 `check-typography.py` 在长文稿上验证。

`PLAYWRIGHT_ENGINE=webkit sh scripts/e2e.sh check-layout-states` 可复验相同的布局和键盘组合；该引擎不提供 CDP 合成触摸接口，脚本明确跳过这三个触摸检查。`REQUIRE_WEBKIT=1 sh scripts/e2e.sh check-reader-code` 与 `check-dialog-focus` 要求两个引擎都安装，避免缺少 WebKit 时把局部通过当成双引擎通过。

主题基准是当前 `PRODUCT.md` 的 25 套：12 套浅色、13 套深色。`DESIGN.md` 中旧的“11 套主题”说明不覆盖用户后续确定的工作坊系列。（2026-11-11 补记：`DESIGN.md` 已改为按天光、四时、工作坊三个系列共 25 套主题描述，此项关闭。）

辅助检查按五个维度进行：DOM/ARIA、键盘与触控、主题对比度、响应式布局、中英文文案与截图。当前环境未找到可执行的 `design-interaction-check`；使用上述专项探针及 Impeccable 检测器补充。检测器对光标、引用线、提示块的侧边线和旧字号说明有规则提示，需按语义和实际渲染核对，不能将装饰性分隔线强行改成控件边界。

## 验收结果

- 26 套已有浏览器检查均取得通过结果。初次 Wiki 回归暴露了视图切换后旧滚动恢复覆盖新定位的问题，控制下一帧后可稳定复现，修复后 Wiki 常规回归和 `view-navigation` 均通过。
- 最后对工具栏、Wiki、阅读、分栏、字号、阅读宽表、对话框及新增专项检查做了 10 套受影响回归，全部通过。
- `layout-states` 最终为 **373 项检查、0 失败**。740×320 的冲突状态下，编辑和阅读正文空间从约 30/26px 增至 **129/125px**，并验证了左右等宽布局、Tab 到末尾工具和真实合成触摸横滑。
- `reader-images` 为 0 失败：原始尺寸四边、键盘平移、尺寸状态、即时语言切换、焦点返回、链接图片及 Markdown 原文保持均验证通过。最后重新构建并复验了白色外层焦点框，确认没有叠加浏览器蓝框。
- `npm run check`、构建、`go test ./...`、前端搜索/标签/反链契约检查、85 个文件的文案扫描、25 套主题对比度基准及 `git diff --check` 通过。原生设置另有中英文、浅深主题、小窗口和大字/高对比度离屏截图。
