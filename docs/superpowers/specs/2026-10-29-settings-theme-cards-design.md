# 设置窗口中的主题卡片

用户要求按提供的原「外观与排版」截图重新设计主题设置。界面验收后纳入 0.6.7；提交与发布准备记录另见版本验收文档。

独立设置窗口继续容纳外观、随手记和语言。外观页恢复两组主题卡片：天光六张，显示时辰大字、名称及底部色线；四时五张，显示主题名称、季节和左侧色条。颜色和字体声音沿用现有主题，选中卡片有边框和勾选标记，悬停或键盘聚焦时显示主题说明。

自动切换恢复四段选择，模式说明置于其下。跟随系统时显示浅色/深色主题选择；字号与行宽并排。选择立即生效，手动选择主题关闭自动切换，关闭自动切换保留当前实际显示的主题。窗口高度不足时内容滚动，控件不重叠，编辑位置和文稿不受影响。

原生设置使用 MyGo UI 的无样式单选与分段控件，复用其键盘和辅助功能行为。卡片及整个设置窗口从 `src/themes.css` 的现有角色读取配色，不维护另一套色值；当前主题计算使用设置窗口的系统深浅色，避免选中深色主题后改变「跟随系统」的判断。中英文使用现有本地化文案，字体只选系统字体。

实施与验证：

- 先调整设置交互回归，确认无需打开下拉菜单即可看见、选择十一套主题；检查选择、自动切换和编辑偏好保持。
- 将主题卡片及配色适配集中在小文件，设置窗口负责布局与状态。保持随手记和语言逻辑。
- 使用真实 MyGo UI 测试检查卡片与分段控制的点击、键盘、深浅色和中英文布局；运行 Go 测试、竞态与 Windows 静态检查。
- 构建隔离的临时验收包，在独立数据目录中核对实际设置窗口。正式安装的留白和用户文稿不参与验收。

验收结果（2026-10-29）：

- 设置窗口默认 720 × 760，最小 640 × 500。中英文十一套主题直接可见，长英文主题名换行；保留系统标题栏。卡片、自动切换与排版控件使用明确的辅助功能名称，卡片同时提供主题说明。
- MyGo UI 回归覆盖主题点击、跨系列键盘选择、点击已选主题关闭自动切换、关闭自动切换保留实际主题、系统深浅色与手动深色互不干扰、小窗口滚动及排版保存不改变编辑偏好。
- 独立代码审查提出一项 P2：自定义配色覆盖了系统文字放大和增强对比度。已补上这些偏好，并让大字模式中的卡片、自动切换及排版控件换行；新增回归先失败、修复后通过。
- 最终 `go test -race ./... -count=1`、`go vet ./...`、`GOOS=windows GOARCH=amd64 go vet ./...` 和 `git diff --check` 均通过。前端 `npm run check`、`npm run build` 通过。
- 最终 `go tool mygo build -platform darwin/arm64` 临时包构建通过，仅使用 ad hoc 签名。通过独立 bundle ID 和数据目录检查实际 macOS 窗口，确认中文浅色、英文深色、语言切换和最小窗口滚动效果。验收进程已关闭，未提交、推送或发布。
