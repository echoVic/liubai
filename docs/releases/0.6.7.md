# 留白 0.6.7

- 全文搜索：侧栏可搜索标题和完整 Markdown，显示命中行号与片段，点击跳到原文，也可在源码中查看。
- 标签筛选：点击文稿旁的标签，或从侧栏选择标签。标签来自文稿属性中的 `tags`，可以与全文搜索一起使用。
- 双链与反向链接：用 `[[文稿名]]` 引用文稿。编辑时 ⌘/Ctrl 点击、阅读和分栏预览中直接点击；同名文稿先选择目标。侧栏反向链接可跳回引用位置，导出保留原始引用文字。
- 文内查找：浮动面板支持查找、替换、大小写、完整单词及正则表达式；阅读时可查找排版后的正文。
- 独立设置窗口：外观、随手记和语言集中设置，修改立即生效。主题沿用「天光」「四时」卡片，保留配色色条与选中勾，自动切换改为分段按钮。
- 随手记：支持模板、标签和追加到已有草稿或文稿，保留原稿待保存文字和撤销历史。
- 修复搜索跳转中途开始组合输入时的原稿保留和保存问题；修复追加速记后的查找计数，以及阅读查找中的软换行和连续空格匹配。

macOS 安装包同时支持 Apple Silicon 和 Intel。

Windows 版仍为内测版，提供 x64 与 ARM64 安装包。目前 Windows 程序和安装包没有代码签名证书，SmartScreen 可能提示「Windows 已保护你的电脑」；需要点「更多信息」→「仍要运行」。应用内更新包另有签名校验。
